# Обо мне
Я - backend-разработчик на Python. Проектирую и реализую API, автоматизирую рутинные процессы, интегрирую сторонние сервисы и разрабатываю Telegram-ботов. В работе использую FastAPI, aiohttp, Pydantic, asyncio, SQLAlchemy, pytest, aiogram 3 и Flask, подбирая инструменты под задачу: от быстрых скриптов-автоматизаций до асинхронных сервисов с интеграциями.

Пишу тесты, работаю с Linux и Docker, довожу решения до рабочего состояния и поддерживаю их после запуска.
